Lesson 4: Cybersecurity & Encryption

Cybersecurity involves protecting systems, networks and programs from digital attacks. Encryption is one technique used to scramble data so that only authorised parties can read it.

Malware

Malware is malicious software designed to damage or gain unauthorised access to a system. Common types include viruses, worms and ransomware.

Encryption

Encryption converts plaintext into ciphertext using an algorithm and a key. Only someone with the corresponding key can decrypt the message. HTTPS uses encryption to secure web traffic.
