Lesson 1: Algorithms & Programming Basics

In this lesson you will learn about the building blocks of programming. Computers use variables to store values, conditionals to make decisions, and loops to repeat instructions. Understanding these concepts is key to writing algorithms that solve problems.

Variables

A variable is a named location in memory used to store a value. In JavaScript you can declare a variable using let or const:

let score = 0;
const name = 'Ada';

Conditionals

Conditionals allow your program to choose different paths of execution. The simplest conditional is the if statement:

if (score > 10) {
    console.log('You win!');
} else {
    console.log('Keep trying!');
}

Loops

Loops repeat instructions multiple times. A for loop repeats a block of code a specified number of times:

for (let i = 0; i < 5; i++) {
    console.log('Iteration ' + i);
}

Interactive Quiz

What does the following JavaScript code output?

let total = 0;
for (let i = 1; i <= 3; i++) {
    total += i;
}
console.log(total);
