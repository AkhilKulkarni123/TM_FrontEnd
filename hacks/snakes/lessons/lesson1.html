Variables

A variable is a named location in memory used to store a value. Think of it as a labeled box where you can keep information. In JavaScript, you can declare variables using let or const:

let score = 0;
const name = 'Ada';

Conditionals

Conditionals allow your program to make decisions and choose different paths of execution. The simplest conditional is the if statement, which acts like a fork in the road:

if (score > 10) {
    console.log('You win!');
} else {
    console.log('Keep trying!');
}

Loops

Loops repeat instructions multiple times, saving you from writing repetitive code. A for loop repeats a block of code a specified number of times:

for (let i = 0; i < 5; i++) {
    console.log('Iteration ' + i);
}
