Lesson 3: Internet & Networking

The internet is a global network of networks. Computers communicate over the internet using unique numerical addresses called Internet Protocol (IP) addresses. To make it easier for humans, domain names map to IP addresses via the Domain Name System (DNS).

IP Addresses

An IPv4 address consists of four numbers between 0 and 255 separated by periods (e.g. 192.168.1.1). Each device on a network has a unique IP address so that data can be routed to the correct destination.

DNS

DNS translates human‑readable domain names (like www.example.com) into IP addresses. DNS servers respond to queries and help your browser locate websites.
