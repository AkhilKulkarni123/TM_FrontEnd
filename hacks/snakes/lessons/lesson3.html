The internet is a global network of networks. Computers communicate over the internet using unique numerical addresses called Internet Protocol (IP) addresses. To make it easier for humans, domain names map to IP addresses via the Domain Name System (DNS).

IP Addresses

An IPv4 address consists of four numbers between 0 and 255 separated by periods. Each device on a network has a unique IP address so that data can be routed to the correct destination.

Example: 192.168.1.1 is a common IP address for home routers. The numbers identify the specific device on the network.

💡 Think of an IP address like a mailing address—it tells the network exactly where to deliver data!

DNS (Domain Name System)

DNS translates human-readable domain names (like www.example.com) into IP addresses. DNS servers respond to queries and help your browser locate websites.

How it works: When you type a website address, your computer asks a DNS server "What's the IP address for this domain?" The DNS server responds with the numeric address, and your browser connects to that IP.

💡 DNS is like a phone book for the internet—it helps you find the right "number" (IP address) for any website!
