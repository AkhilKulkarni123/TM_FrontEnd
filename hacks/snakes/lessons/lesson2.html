Arrays

An array stores an ordered collection of values. Think of it as a numbered list where each item has a position (index). In JavaScript, you declare an array with square brackets:

const fruits = ['apple', 'banana', 'cherry'];
console.log(fruits[1]); // 'banana'

💡 Arrays are zero-indexed, meaning the first item is at position 0!

Objects

An object stores data as key-value pairs. Keys are strings that act like labels, and values can be any type. This structure is perfect for representing real-world entities:

const student = { name: 'Ada', age: 17 };
console.log(student.name); // 'Ada'

💡 Access object values using dot notation (student.name) or brackets (student['name'])!
