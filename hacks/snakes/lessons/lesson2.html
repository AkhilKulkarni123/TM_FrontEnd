Lesson 2: Data Structures

Data structures are ways of organising and storing data in a computer so that it can be accessed and modified efficiently. Two common data structures are arrays (also called lists) and objects (also called dictionaries or maps).

Arrays

An array stores an ordered collection of values. In JavaScript you declare an array with square brackets:

const fruits = ['apple', 'banana', 'cherry'];
console.log(fruits[1]); // 'banana'

Objects

An object stores data as key‑value pairs. Keys are strings and values can be any type:

const student = { name: 'Ada', age: 17 };
console.log(student.name); // 'Ada'
